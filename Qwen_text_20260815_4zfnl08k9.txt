PORTFOLIO ARCHITECTURE — PRODUCTION v2
======================================
Supersedes: portfolio_architecture (2).txt
Companion doc: PORTFOLIO DESIGN SYSTEM — PRODUCTION v2

NORTH STAR
----------
The visitor leaves thinking:
"This person builds. Learns quickly. Understands systems.
Explains complexity clearly. Is worth interviewing."

Design identity: "Cinematic minimalism" — Micro1-style full-screen
scenes + atmospheric depth, combined with one deliberate interactive
adaptation (the About split panel).

Global rules
- High signal, low noise: every sentence earns its place.
- One accent color (#3B82F6), used ONLY for indicators/hovers/diagrams.
- No hard scroll-snap. Lenis smooth scroll + large vertical rhythm
  creates the "scene" pacing.
- Architecture diagrams are ALWAYS visible (core evidence).
  Hover only enhances (zoom + glow), never reveals.
- prefers-reduced-motion: disable Lenis, ambient drift, staggers.

TECH STACK
----------
Next.js 15 (App Router) · TypeScript · Tailwind CSS · Framer Motion ·
Lenis · Shadcn/UI · Lucide Icons
GSAP: ONLY if scroll-linked timeline growth can't be done cleanly in
Framer Motion. Three.js: NOT used (performance budget).

----------------

SECTION 1 — HERO (full viewport "scene")
==================================================
Goal: answer "Who are you?" within 3 seconds.

Background (atmosphere, CSS-only — no photos):
- Base #09090B
- radial-gradient(ellipse at 20% 50%, rgba(59,130,246,0.08), transparent 50%)

  to the 300–1200ms rule; disabled under reduced motion)

Content (centered, Micro1-style):
- Eyebrow (rotating, 100ms fade swap, caption opacity):
  "Building intelligent systems." / "Building scalable backends." /
  "Building AI-powered products." / "Building solutions from first principles."
- Headline (2 lines):
  "Building intelligent systems
   that solve real-world problems."
- Subheading: "Backend • AI • System Design"
- CTAs:
  [View Projects →]  primary white pill, arrow shifts +4px on hover
  [Resume]          ghost pill
- Scroll cue: thin 1px vertical line, subtle loop, bottom center

Entry animation (Design System §Motion): navbar → headline →
subheading → buttons, 100ms stagger, 0.8s, y 40→0.

PRODUCTION REQUIREMENTS
==================================================
Performance
- Lighthouse 95+ on 4G/mid-tier CPU.
- No photos/videos/Three.js/large GIFs. Atmosphere = CSS gradients +
  SVG grain. Diagrams = SVG. Font = Geist via next/font (swap).
- All content data-driven from src/data (copy edits ≠ code edits).

Accessibility
- focus-visible rings on all interactive elements.
- About nav = buttons + aria-current; panel content in live region.
- Body text never below 80% opacity; captions 40% only for ≤14px labels.
- Full prefers-reduced-motion fallback (static, no Lenis).

SEO / Meta
- title: "[Name] — Backend & AI Engineer"
- OG image 1200×630: #09090B bg, hero headline in Geist 600, white.
- Semantic h1→h3 order; one h1 (hero).

CONTENT RULES
- Quantify impact everywhere (%, latency, throughput, score).
- One idea per sentence. No adjectives doing a metric's job.

BUILD ORDER (implementation checklist)
1. Tokens, globals, layout shell, Lenis, reduced-motion guard
2. Navbar + Hero (atmosphere, stagger, CTAs)
3. About (statement + split panel)
4. Projects (featured card + SVG diagrams)
5. Skills · 6. Journey · 7. Notes · 8. Contact
9. Motion pass (easing/timing audit vs Design System)
10. A11y pass · 11. Meta/OG · 12. Lighthouse pass + deploy
